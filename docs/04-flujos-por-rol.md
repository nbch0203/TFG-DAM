# Flujos por rol

Este documento explica qué hace cada tipo de usuario y cómo usa el sistema en el día a día.

## Padres y madres

### Qué pueden hacer

- Ver el autobús asociado a sus hijos.
- Consultar el trayecto en un mapa.
- Recibir avisos sobre la ruta si el sistema los genera.

### Flujo básico

1. Inician sesión.
2. El sistema muestra los hijos vinculados.
3. Seleccionan un hijo.
4. Ven la ruta y el autobús actual en el mapa.

## Conductores

### Qué pueden hacer

- Iniciar una ruta.
- Enviar la ubicación del autobús.
- Finalizar la ruta al terminar el servicio.

### Flujo básico

1. Inician sesión en la app Android.
2. Escogen la ruta asignada.
3. Pulsan iniciar ruta.
4. La aplicación envía la ubicación de forma periódica.
5. Al finalizar, detienen el envío de datos.

## Administración

### Qué pueden hacer

- Crear y editar colegios.
- Gestionar rutas y paradas.
- Registrar autobuses, alumnos y usuarios.
- Ver el estado general del servicio.

### Flujo básico

1. Inician sesión en el panel web.
2. Revisan el dashboard.
3. Gestionan los datos maestros.
4. Comprueban si hay rutas activas y autobuses en marcha.

## Profesorado

### Qué puede hacer

El proyecto menciona este rol, pero su alcance exacto aún no está cerrado. Por ahora se entiende como un perfil de consulta o apoyo relacionado con el transporte escolar.

## Resumen rápido

| Rol | Función principal |
|---|---|
| Padres y madres | Seguir el autobús y consultar el estado del trayecto. |
| Conductores | Enviar ubicación y controlar la ruta. |
| Administración | Gestionar toda la información del sistema. |
| Profesorado | Consulta o apoyo, pendiente de concretar. |
