# Guía de lectura

Esta guía te dice qué documento leer primero según lo que quieras entender. Está pensada para alguien que llega al proyecto por primera vez.

## Si quieres una explicación rápida

Lee primero [01-vision-general.md](01-vision-general.md). Resume qué es SchoolSafeTrack, qué problema resuelve y quién lo usa.

## Si quieres entender cómo funciona

Después lee [02-arquitectura.md](02-arquitectura.md) para ver cómo se conectan la web, la app, el backend y la base de datos.

## Si quieres saber qué hace cada usuario

Lee [04-flujos-por-rol.md](04-flujos-por-rol.md). Explica las funciones de padres, conductores, administración y profesorado.

## Si quieres probarlo o arrancarlo

Lee [guia-pruebas.md](guia-pruebas.md). Tiene los pasos básicos para levantar el proyecto y comprobarlo.

## Si quieres trabajar en el código

Según qué parte del sistema quieras modificar:

- **Para el backend**: lee [backend/README.md](backend/README.md) para entender API, rutas y base de datos.
- **Para el frontend web**: lee [frontend-web/README.md](frontend-web/README.md) para aprender sobre pantallas y componentes.
- **Para la app Android**: lee [aplicacion-android/README.md](aplicacion-android/README.md) para trabajar en la app móvil.

Antes de cualquiera de esos, lee [05-guia-desarrollador.md](05-guia-desarrollador.md) para entender la estructura general del proyecto.
